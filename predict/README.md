# 마이크론(MU)으로 SK하이닉스(000660) 예측

마이크론 주가로 SK하이닉스 주가를 예측하는 파이썬 프로그램입니다.
표준 라이브러리만 사용하며(numpy/pandas 불필요), 추가 설치가 필요 없습니다.

## 왜 되는가 (아이디어)

- 마이크론과 하이닉스는 같은 **메모리 반도체(DRAM/NAND)** 업종이라 주가 상관이 매우 높습니다.
- 마이크론은 미국 시장에서 **한국시간 밤(≈UTC 21시)** 에 거래를 마치므로,
  하이닉스의 **다음 거래일**(≈UTC 06:30 마감) 종가보다 정보가 먼저 확정됩니다.
- 이 **시차(lead-lag)** 를 이용해 다음을 선형회귀로 학습합니다.

  ```
  하이닉스 당일 로그수익률  ~  마이크론 '전일(이상)' 로그수익률
  ```

  전일 이상만 특징으로 쓰므로 **미래참조(look-ahead)가 없습니다.**

## 데이터

이미 배포된 대시보드의 공개 JSON(약 5년 일봉)을 그대로 사용합니다.

- 마이크론: `https://chorus96.github.io/study/micron/data.json`
- 하이닉스: `https://chorus96.github.io/study/hynix/data.json`

형식: `{ "points": [ { "t": <unix초>, "c": <종가> }, ... ] }`

같은 형식의 **로컬 JSON 파일**을 `--micron` / `--hynix`로 넘겨도 됩니다.
(네트워크가 막힌 환경에서는 로컬 파일을 쓰세요.)

## 실행

```bash
# 대시보드 공개 데이터로 실행 (기본: 마이크론 전일 수익률 사용)
python3 predict_hynix_from_micron.py

# 마이크론 1·2일 전 수익률을 함께 사용
python3 predict_hynix_from_micron.py --lags 1 2

# 로컬 파일 사용
python3 predict_hynix_from_micron.py --micron mu.json --hynix hy.json

# 검증(테스트) 비율 조정 (기본 0.2 = 뒤쪽 20%)
python3 predict_hynix_from_micron.py --test-frac 0.3
```

## 출력 항목

- **데이터 요약** — 각 종목 일수, 공통 거래일, 기간
- **당일 상관계수** — 참고용(동시점이라 예측엔 사용 불가)
- **모델 계수** — 절편과 각 lag 계수(마이크론 1% 변동 시 하이닉스 방향)
- **성능** — 학습/검증 구간의 R², RMSE, 방향적중률, 상관
- **베이스라인** — "항상 상승" 가정의 방향적중률(비교 기준)
- **다음 거래일 예측** — 최신 마이크론 수익률로 계산한 하이닉스 예상 수익률·종가

## 해석 시 주의

- **일간 수익률** 예측의 설명력(R²)은 원래 낮은 것이 정상입니다.
- 검증 구간 **방향적중률이 베이스라인과 비슷하면** 실질적 예측력이 거의 없다는 뜻입니다.
- 과거 상관이 미래를 보장하지 않습니다.
- **학습·연구용 예시이며 투자 자문·매매 권유가 아닙니다.** 투자 판단은 본인 책임입니다.
