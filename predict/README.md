# 마이크론·엔비디아 → SK하이닉스(000660) 예측

마이크론(MU)·엔비디아(NVDA)의 '밤사이' 움직임으로 SK하이닉스를 예측하는 파이썬
프로그램입니다. 표준 라이브러리만 사용하며(numpy/pandas 불필요) 추가 설치가 없습니다.

## 왜 되는가 (아이디어)

- 마이크론·엔비디아·하이닉스는 같은 **반도체** 업종이라 상관이 높습니다.
- 미국 종목은 **한국시간 밤**(≈UTC 21시)에 마감 → 하이닉스의 **다음 거래일**
  (≈UTC 06:30 마감) 종가보다 정보가 먼저 확정됩니다.
- 이 **시차(lead-lag)** 를 이용해 다음을 예측합니다.

  ```
  하이닉스 로그수익률  ~  '직전에 마감된' 미국 종목(마이크론·엔비디아) 로그수익률
  ```

  각 하이닉스 종가 **직전**의 미국 종가만 쓰므로 **미래참조(look-ahead)가 없습니다.**

## 이 모델의 특징

1. **정밀 시점 정렬** — UTC 날짜로 묶지 않고, 각 하이닉스 종가 시각 '직전'에 마감된
   미국 종가를 타임스탬프로 직접 찾습니다(서머타임·휴장일에도 정확).
2. **선행지표 확대** — 마이크론에 더해 **엔비디아** 밤사이 수익률을 특징으로 추가.
   특징 표준화 + **릿지(L2) 정규화**로 안정화.
3. **방향 예측(로지스틱)** — 수익률 크기 회귀(예상 종가용)와 별도로, 상승/하락
   **확률**을 로지스틱 회귀로 직접 예측합니다.
4. **정직한 평가** — 단일 분할이 아니라 **워크포워드(확장창) 표본외 검증**을 하고,
   세 가지 **베이스라인**(항상 같은 방향 / 하이닉스 모멘텀 / 미국 신호 그대로)과
   비교해 실질 예측력을 판정합니다.

## 데이터

배포된 대시보드의 공개 JSON(약 5년 일봉)을 그대로 사용합니다.

- 하이닉스: `https://chorus96.github.io/study/hynix/data.json`
- 마이크론: `https://chorus96.github.io/study/micron/data.json`
- 엔비디아: `https://chorus96.github.io/study/nvidia/data.json`

형식: `{ "points": [ { "t": <unix초>, "c": <종가> }, ... ] }`

같은 형식의 **로컬 파일**을 `--hynix` / `--micron` / `--nvidia`로 넘겨도 됩니다.

## 실행

```bash
python3 predict_hynix_from_micron.py                 # 대시보드 공개 데이터(MU+NVDA)
python3 predict_hynix_from_micron.py --no-nvidia     # 마이크론만 사용
python3 predict_hynix_from_micron.py --lam 2 --step 5 # 릿지 세기·워크포워드 간격 조정
python3 predict_hynix_from_micron.py --hynix hy.json --micron mu.json --nvidia nv.json
```

## 출력 항목

- **데이터 요약** — 하이닉스 일수, 사용 특징, 정밀 정렬 표본·기간
- **모델 계수** — 수익률 회귀(릿지 OLS)와 방향 로지스틱 각각의 계수(표준화 기준)
- **표본외(워크포워드) 성능** — 방향적중·R²·RMSE, 그리고 세 베이스라인과의 비교 및
  "최고 베이스라인 대비 ±%p" 판정
- **다음 거래일 예측** — 상승 확률(로지스틱) · 예상 수익률(회귀) · 예상 종가

## 해석 시 주의

- **일간** 수익률 예측의 R²는 원래 낮은 것이 정상입니다.
- 표본외 **방향적중이 베이스라인과 비슷하면** 실질적 예측력이 거의 없다는 뜻입니다.
- 과거 상관이 미래를 보장하지 않습니다.
- **학습·연구용 예시이며 투자 자문·매매 권유가 아닙니다.** 투자 판단은 본인 책임입니다.
