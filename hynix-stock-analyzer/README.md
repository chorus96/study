# SK하이닉스(000660) 기술적 분석 대시보드

개인 폰에서 열어 쓰는 모바일 웹 대시보드입니다. 일별 종가만 붙여넣으면
이동평균선·RSI·MACD·볼린저밴드를 계산하고, 매수/중립/매도 종합 신호를
차트와 함께 보여줍니다.

## 특징
- **완전 오프라인 단일 파일** (`index.html`) — 외부 라이브러리·네트워크 요청 없음
- **한국 시장 관례** 반영: 상승=빨강, 하락=파랑
- **지표**: MA5·20·60, RSI(14), MACD(12·26·9), 볼린저밴드(20, 2σ)
- **종합 신호 스코어**(±8): 이평선 배열·20일선 대비·RSI·MACD·볼린저 위치를 합산
- 라이트/다크 테마 자동 대응, 터치 크로스헤어 툴팁
- 종가를 직접 붙여넣어 분석 (네이버·증권사 앱에서 복사)

## 사용법
1. 폰 브라우저에서 `index.html`을 엽니다. (파일을 열거나, GitHub Pages 등으로 배포)
2. 기본값은 **임의로 생성한 예시 데이터**로 즉시 작동합니다.
3. 하단 **"내 데이터로 분석하기"**를 눌러 실제 일별 종가를 붙여넣고
   **분석하기**를 누르면 내 데이터로 다시 계산됩니다.

## 주의
투자 참고용 계산 도구이며, 투자 자문·매매 권유가 아닙니다.
기본 데이터는 실제 시세가 아닙니다. 투자 판단과 책임은 이용자 본인에게 있습니다.
