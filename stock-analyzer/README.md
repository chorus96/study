# 반도체 대장주 기술적 분석 대시보드 (하이닉스·삼성전자·마이크론·엔비디아)

개인 폰에서 열어 쓰는 모바일 웹 대시보드입니다. 상단 스위처로 **SK하이닉스(000660)**,
**삼성전자(005930)**, **마이크론(MU)**, **엔비디아(NVDA)** 4개 종목을 전환하며,
**실시간(지연) 시세를 자동으로 받아** 이동평균선·RSI·MACD·볼린저밴드를 계산하고,
매수/중립/매도 종합 신호를 차트와 함께 보여줍니다. 최신 뉴스 헤드라인의 **키워드
기반 간이 심리**도 종목별로 함께 표시합니다. 실시간 데이터가 없으면 예시 데이터로
즉시 동작합니다. (국내 종목은 원화, 미국 종목은 달러로 표시)

## 동작 방식 (2가지 모드)
1. **실시간(지연)** — GitHub Pages로 배포하면 같은 출처의 종목별 `data.json`
   (`hynix/`·`samsung/`·`micron/`·`nvidia/`)을 읽어 최신 시세로 분석합니다.
   (아래 "실시간 설정" 참고)
2. **예시(샘플)** — 데이터가 없을 때(오프라인) 임의 생성 예시로 즉시 작동.

## 특징
- **단일 파일**(`index.html`) · 외부 라이브러리 없음 · 라이트/다크 자동 대응
- **종목 스위처**: 하이닉스·삼성전자·마이크론·엔비디아 (각각 실시간 시세·뉴스 심리 개별 표시)
- **통화 자동 대응**: 국내(KRW·원) / 미국(USD·달러)
- **색상 관례**: 상승=빨강, 하락=파랑 (모든 종목에 한국 시장 관례 일관 적용)
- **지표**: MA5·20·60, RSI(14), MACD(12·26·9), 볼린저밴드(20, 2σ)
- **PER(주가수익비율) 일별 추이**: 국내 종목만 pykrx로 제공(무키). 미국 종목은
  무료 PER 시계열 소스가 없어 안내만 표시.
- **영업이익(연간) 막대그래프**: 국내는 **DART**(전자공시), 미국은 **FMP** 무료
  키로 최근 5개년 영업이익을 표시(적자 연도는 파란 막대). 키가 없으면 카드 숨김.
- **종합 신호 스코어**(±8): 이평선 배열·20일선 대비·RSI·MACD·볼린저 위치 합산
- **뉴스 심리(간이)**: Google News 헤드라인을 **키워드 규칙**으로 집계해
  긍정/중립/부정을 표시 (API 키·비용 없음, LLM 분석 아님)
- 터치 크로스헤어 툴팁, 날짜 축, 범례 토글

## 실시간 설정 (최초 1회)
실시간 시세는 CORS·CSP 제약 때문에 브라우저가 외부 API를 직접 부를 수 없어,
**GitHub Actions가 서버에서 시세를 받아 GitHub Pages로 함께 배포**하는 구조입니다.

1. 이 브랜치를 기본 브랜치(`main`)로 병합합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를
   **"GitHub Actions"**로 설정합니다.
3. **Actions** 탭에서 `Deploy stock dashboard (live data)` 워크플로를
   한 번 실행(`Run workflow`)하거나, 스케줄(평일 09:00–15:30 KST, 30분 간격)을
   기다립니다.
4. 배포 완료 후 나오는 Pages URL(`https://chorus96.github.io/study/`)을
   폰 홈 화면에 추가해 앱처럼 사용합니다. (앱은 상대 경로로 종목별 `data.json`을
   읽으므로 프로젝트 경로가 바뀌어도 동작합니다.)

데이터 소스는 시장별로 여러 곳을 순서대로 시도합니다.
- **국내(KRX)**: Yahoo → Stooq(.kr) → **pykrx(KRX 공식, 무키)** → Twelve Data / FMP(선택).
  러너(Azure IP)에서 Yahoo가 차단(429)돼 실제로는 `pykrx`가 KRX 공식 데이터를 받아옵니다.
- **미국(NASDAQ)**: Yahoo → **Stooq(.us, 무키)** → Twelve Data / FMP(선택).
  pykrx는 국내 전용이라 건너뛰고, 무키로 쓸 수 있는 **Stooq**가 미국 일봉을 받아옵니다.

네 종목의 `data.json`은 배포 시 러너에서 `hynix/`·`samsung/`·`micron/`·`nvidia/`
하위에 각각 생성되며 저장소에는 커밋되지 않습니다(`.gitignore`). 갱신 주기·종목은
`.github/workflows/deploy.yml`, `scripts/fetch_stock.sh`에서 조정할 수 있습니다.

PER 추이는 `scripts/fetch_fundamentals.sh`가 국내 종목에 한해 **pykrx(무키)**로
일별 PER 시계열을 받아 종목별 `fundamentals.json`으로 저장합니다. 미국 종목의 과거
PER 시계열은 무료 티어에 없어 생략합니다.

영업이익(연간)은 `scripts/fetch_financials.sh`가 국내는 **DART 오픈API**
(`DART_API_KEY` 시크릿 + 종목별 `corp_code`), 미국은 **FMP**(`FMP_API_KEY` 시크릿)
로 받아 `financials.json`으로 저장합니다. 두 키 모두 **무료(카드 불필요)**이며,
없으면 해당 카드는 자동으로 숨겨집니다.

뉴스 심리는 `scripts/fetch_news.sh`가 **Google News RSS(키 불필요)**에서 종목별
최신 헤드라인을 받아, 한국어 금융 키워드(예: `수주·신고가·흑자` = 긍정, `급락·감소·
우려` = 부정)를 규칙 기반으로 집계해 종목별 `news.json`으로 저장합니다. **API 키나
비용이 필요 없으며 LLM 분석이 아닙니다.** 규칙 기반이라 오판이 있을 수 있으니 원문
링크로 사실관계를 확인하세요. (`news.json`도 배포 시 생성되며 커밋되지 않습니다.)

> 참고: 무료 데이터는 실시간 대비 지연(약 15분)될 수 있고, GitHub Actions 스케줄도
> 다소 지연될 수 있습니다. 배지의 "갱신" 시각으로 최신 여부를 확인하세요.
